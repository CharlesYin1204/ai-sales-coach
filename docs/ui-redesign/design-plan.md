# 鲸策 UI 改版设计

## 方向
销售管理者每天回到接待原文，核对判断，再形成下一次接待的具体行动。以“对话的声波 → 有据可查的片段 → 辅导行动”为视觉主线。首页采用宽幅声波与可切换的接待实例；应用导航像一条稳定的深海色侧栏，主工作区用清透的白与浅蓝。

## 设计规范
- 深海：#153447，导航和品牌主色；阅读墨色：#203447。
- 行动蓝：#3267E3，主要操作；冰蓝：#EEF3F9，工作画布。
- 白：#FFFFFF，阅读内容；珊瑚：#E89679，声波与待处理的有限强调。
- 中文使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC 系统字体，16px正文、14px表格、12px辅助信息；标题28–56px，字重600–700。品牌与数值采用 Avenir Next / Trebuchet MS，数字等宽。
- 页面左对齐，桌面侧栏248px，主内容最大1600px。首页左右交错而非均匀卡片堆叠；后台以任务优先。
- 边框用于划分数据，阴影仅用于浮层、菜单与首页接待演示。圆角按层级使用：按钮10px、面板16px、品牌主视觉28px。

## 结构推演
方案A：标题 + 三个均匀功能卡 + 指标卡网格（舍弃，无法体现对话工作）。
方案B（采用）：首页接待实例作为主视觉；业务区围绕原文与操作组织。

首页：[品牌 / 导航] → [主张与入口 | 可切换的对话实例] → [原文 / 复核 / 行动的流程] → [团队工作区入口]
应用：[深海导航 | 标题与上下文 → 统一统计条 → 对话队列 + 下一步行动 → 辅导]
详情：[原文阅读区 | 结论与证据 / 人工复核]
助手：[会话目录 | 上下文选择 → 聊天阅读 → 输入]

## 开发前复核
保留“鲸策”的销售辅导语境，不引入无意义数字、虚构经营提升或装饰性全大写标签。首页示例明确标记为演示。将原先普遍的小字和浅灰绿文字提高到可读尺寸及对比度。应用中取消每个标题上方的英文装饰标签。

## 验收
逐页桌面和390px/768px手机平板截图；检查横向溢出、导航、表格内部滚动、表单、模态框、助手输入、错误状态、键盘焦点及减少动画偏好。构建成功后部署至原端口3030，登录、权限及AI接口保持使用既有服务。

## 第一轮截图复查
已检查首页、工作台、AI模型管理、登录和手机助手。去掉原有全站英文标题装饰；保留少量说明性标签。全站字体不依赖运行时外部Google字体请求，中文优先使用设备原生字体。将辅助信息中偏浅的灰蓝加深、表格主要文字提高至13px；小屏关键输入和选择控件使用16px，避免输入时自动缩放。复盘示例没有虚构业绩指标。新增的声波是示意图形，不声称来自用户真实录音。

界面验收脚本覆盖1440×1050、768×1024和390×844；长表格在容器内滚动，页面本身不横向溢出。原业务API与数据库结构在本次UI改版中没有变更。
